# Neovim 按键功能详解：常用与不常用

适用对象：这台 Fedora 笔记本当前使用的 Neovim 配置。核对日期：**2026-10-18**。

- Neovim：`0.12.5`；配置框架：AstroNvim `6.1`。
- 配置仓库：<https://github.com/dusknobo/nvimConfig>；核对时提交：`b29d990`。
- 已启用的本地开发功能：C++/Rust 语言服务、clang-format、LLDB、异步 CMake、Markdown 渲染。
- 快捷键依据当前配置、已连接 clangd 的 C++ 缓冲区、Markdown 缓冲区以及文件树/选择器配置核对；部分按键随文件类型或所在界面变化。
- **按功能分章，每章再分“常用”和“不常用”。**“不常用”表示进阶或按需使用，不代表没有配置；你经常调试时，调试键也可以成为常用键。

这份手册只说明操作，不更改任何按键，并随 nvim 配置仓库发布。本机阅读副本与简明版 `niri-zellij-shortcuts.md` 统一存放在 `~/Documents/Manuals/`。

## 阅读方法与按键记法

### 按键记法

| 记法 | 怎样按 | 示例 |
|---|---|---|
| `+` | 同时按住 | `Ctrl+r`：按住逻辑 Ctrl，再按 r |
| `→` 或键之间的空格 | 依次按，前一键可以松开 | `Space → m → b`、`Space m b` 都是先空格，再 m，再 b |
| 连写的小写字母 | 普通模式下依次输入 | `gd` 是 g、d；`ciw` 是 c、i、w |
| 大写字母 | 按住 Shift 输入该字母 | `G` 是 Shift+g；`Space l R` 最后一个是大写 R |
| `<Leader>` | 当前配置里就是 Space | `<Leader>ff` 等于 `Space → f → f` |
| `:命令` | 普通模式按冒号，输入命令，再按 Enter | `:CMakeBuild`、`:w` |
| `3w`、`5j` | 数量加动作 | 向后移动 3 个单词、向下移动 5 个逻辑行 |
| `[d`、`]q` | 方括号也是要按的实体字符 | `[d` 是左方括号、d，不含 Ctrl |

表格中斜杠通常表示两个备选键，例如 `h / l` 表示按 h 或 l，不用真的输入 `/`。搜索键单独写为 `/` 时才是按斜杠。

### 模式与按键生效范围

| 标记 / 模式 | 含义 | 如何进入 / 离开 |
|---|---|---|
| N：普通模式 | 移动、删除、复制、触发多数插件操作 | 按 Esc 返回，即物理任一 Ctrl |
| I：插入模式 | 输入文字、使用补全菜单 | 普通模式按 i/a/o 等进入；Esc 离开 |
| V：可视模式 | 选择文字、对选区操作 | 普通模式按 v/V/Ctrl+v；Esc 取消 |
| O：操作符等待 | 已按 d/c/y 等，等待指定作用范围 | 例如先 d，再 iw；Esc 取消 |
| C：命令行模式 | 输入冒号命令或搜索表达式 | 普通模式按 `:`、`/` 或 `?`；Enter 执行，Esc 取消 |
| T：终端输入模式 | 按键发送给内嵌 Fish/运行程序 | 在终端里进入输入状态；用专门按键返回终端普通模式 |
| 插件界面 | 文件树、搜索框、调试面板等 | **局部映射优先**，不要把源文件里的同一个键机械套用过去 |

**没有特别说明的 `Space ...` 快捷键，先回到普通模式再按。**在插入模式按 Space 通常只是输入空格。

| 类别 | 最值得先记的键 | 功能 |
|---|---|---|

| 撤销 | `u`、`Ctrl+r` | 撤销、重做 |
| 查找文件 | `Space f f` | 在项目文件中查找 |
| 搜索内容 | `Space f w` | 搜索项目文本 |
| 文件树 | `Space e` | 显示或隐藏文件树 |
| 文件切换 | `Space f b` | 在已打开文件中选择 |
| 跳转 | `gd`、`K` | 定义、说明文档 |
| 重命名 | `Space l r` | 语言服务重命名符号 |
| 格式化 | `Space l f` | 格式化当前文件 |
| 诊断 | `[d`、`]d` | 上一条、下一条诊断 |
| 构建 | `Space m b` | 配置并构建 CMake 工程 |
| 测试 | `Space m t` | 配置、构建、运行 CTest |
| Markdown | `Space u m` | 开关 Markdown 渲染 |
| 发现更多按键 | `Space f k` | 搜索已配置的快捷键；也可按 Space 后等待分组提示 |

### 三层窗口不要混淆

| 你想控制的对象 | 使用哪套键 |
|---|---|
| Niri 桌面里的应用窗口 / 工作区 | `Alt+...` |
| Zellij 的窗格 / 标签页 | `Win+...` |
| 同一个 Neovim 内部的窗口 / 缓冲区 / 标签页 | 本文的 `Ctrl+w ...`、`Space ...` 等 |

终端中如果运行着 Zellij，Win 组合键仍然先由 Zellij 处理；Niri 的 Alt 键也可能先于 Neovim 接收到。当前自动括号插件中的 `Alt+e` 还会与桌面 `Alt+E` 文件管理器冲突，**本手册不把它当作可直接使用的编辑入口**。

> 安全提醒：普通编辑窗口中的 `Ctrl+q` 当前被配置成强制退出当前窗口，可能丢失未保存修改。它不作为可视块选择键使用；块选择使用 `Ctrl+v`。`Space q` 是带确认的关闭窗口，`Space c` 是关闭缓冲区，`Alt+Q` 则会关闭整个桌面应用窗口。

## 模式与输入：先看当前在什么模式

本部分以 Neovim 的原生命令为主。`普通`表示普通模式，`插入`表示插入模式，`可视`表示已有选区，`命令`表示先按 `:` 再输入命令并回车。大写字母必须按 Shift；`gg` 是连续按两次 g，`Ctrl+w h` 是先按 Ctrl+w，再松开并按 h。

### 常用

| 按键 | 模式 | 作用与使用场景 |
|---|---|---|
| `Esc` | 插入／可视／命令 | 取消当前输入或选区，返回普通模式。笔记本已换键：按物理左／右 Ctrl 才会发送 Esc；物理 Esc 现在是 CapsLock。 |
| `i` / `a` | 普通 | 分别在光标之前／之后开始输入。不要在插入模式反复按 i，它只会输入字母。 |
| `I` / `A` | 普通 | 到当前行第一个非空白字符前／行末开始输入。适合加行首关键字或行尾分号。 |
| `o` / `O` | 普通 | 在当前行下方／上方新建一行并进入插入模式；通常沿用当前缩进。 |
| `v` / `V` | 普通 | 分别开始按字符／按整行选择；移动光标扩大选区，再按 d、y 或其他操作符。 |
| `:` | 普通 | 进入命令行。例如 `:w` 保存，`:q` 关闭当前窗口。命令输入后按 Enter 执行。 |

### 不常用

| 按键 | 模式 | 作用与注意事项 |
|---|---|---|
| `Ctrl+v` | 普通 | 开始矩形块选择，适合批量编辑多行的同一列。这里的 Ctrl 是物理 CapsLock；不要用 Ctrl+q 代替，当前配置把 Ctrl+q 用于强制退出。 |
| `gv` | 普通 | 恢复上一次可视选区；选区位置可能随文本编辑变化。 |
| `R` | 普通 | 进入替换模式，输入字符逐个覆盖原字符；按 Esc 退出。与只替换一个字符的 `r` 不同。 |
| `Ctrl+[` | 插入／可视 | 另一种发送 Esc 的方式；当前物理组合是 CapsLock+[。 |
| `Ctrl+o` | 插入 | 临时执行一个普通模式命令，然后继续输入。例如 `Ctrl+o A` 移到行末并继续输入。与普通模式的 Ctrl+o“跳回”不同。 |

块选择批量插入示例：普通模式按 `Ctrl+v` → 用 j/k 选中多行 → 按大写 `I` → 输入前缀 → 按 Esc。前缀会应用到所选各行；先在临时文本中练习。可视模式的行为可查 [官方 Visual 帮助](https://neovim.io/doc/user/visual/)。

## 新建、保存、关闭与缓冲区栏

“关窗口”“关缓冲区”“退出整个 Neovim”不是同一件事。缓冲区中的未保存内容仍在内存里，不能因为已经切换到另一个文件就认为它已保存。

### 常用

| 按键 / 命令 | 模式 | 功能与使用场景 |
|---|---|---|
| `Space n` | 普通 | 新建一个空缓冲区，尚未给出磁盘文件名。首次保存可用 `:w 路径`。 |
| `Space w` / `:w` | 普通 / 命令 | 保存当前文件。推荐日常使用这个入口并留意错误消息。 |
| `:wa` | 命令 | 保存所有需要写入的缓冲区；构建依赖多个改过的源文件/头文件时很实用。无文件名或写入失败时仍需处理报错。 |
| `Space q` | 普通 | 关闭当前 Neovim 窗口，有相关未保存修改时提供确认；最后一个窗口关闭后可能退出编辑器。 |
| `Space c` | 普通 | 关闭当前文件缓冲区，与关闭分屏窗口不同；留意未保存内容的提示。 |
| `Space f b` | 普通 | 搜索并切换已打开缓冲区，适合文件较多时使用。 |
| `[b` / `]b` | 普通 | 切换上一个 / 下一个缓冲区；不是上下工作区。 |
| `Space b b` | 普通 | 根据顶部缓冲区栏的选择提示切换文件，显示提示后再按对应标识。 |
| `:e 文件名` | 命令 | 编辑给定文件，例如 `:e src/main.cpp`。文件存在时打开，不存在时先建立对应缓冲区。 |

### 不常用

| 按键 / 命令 | 模式 | 功能与风险 |
|---|---|---|
| `Space Q` | 普通 | 退出整个 AstroNvim，命令带确认；大写 Q。先检查需要保留的文件。 |
| `Space C` | 普通 | **强制关闭当前缓冲区**；大写 C，可能丢失未保存改动。 |
| `Ctrl+q` | 普通编辑窗口 | **强制关闭当前窗口**，对应 `q!`；不是整个会话的通用安全退出，也不是块选择。插件局部面板可能覆盖此键。 |
| `Ctrl+s` | 普通 / 可视 | 当前配置尝试 `silent! update!` 强制写入；失败消息可能被抑制，不能用“没有报错”推断保存成功。日常优先 `Space w`。**插入模式同键是参数提示。** |
| `:wq` / `:x` | 命令 | 保存并关闭窗口；`:x` 在需要时才写入。最终是否退出整个程序取决于剩余窗口。 |
| `:saveas 新路径` | 命令 | 写入新路径并把当前缓冲区名称切换过去；不是“删除旧文件”。先确认目的文件是否已存在。 |
| `Space R` | 普通 | 重命名文件；大写 R。不同于 `Space l r` 的代码符号重命名，操作后检查实际路径与 Git 状态。 |
| `Space b d` | 普通 | 按缓冲区栏提示选择要关闭的缓冲区，不要求先切换到那个文件。 |
| `Space b c` / `Space b C` | 普通 | 关闭其他缓冲区 / 关闭全部缓冲区；大写 C 的范围更大，先保存重要内容。 |
| `Space b l` / `Space b r` | 普通 | 关闭缓冲区栏当前项左侧 / 右侧的文件项；不是移动光标。 |
| `<b` / `>b` | 普通 | 将当前缓冲区在顶栏中向左 / 右调整顺序；先按小于号 / 大于号，再按 b。 |
| `Space b s e` / `Space b s p` | 普通 | 按扩展名 / 完整路径排序缓冲区栏。排序只调整栏位，不移动磁盘文件。 |
| `Space b s i` / `Space b s m` / `Space b s r` | 普通 | 按缓冲区编号 / 修改状态 / 相对路径排序。 |

关闭文件、切换窗口或退出编辑器，都不等价于提交 Git。需要确认磁盘上的结果时查看保存消息、文件修改标记和版本控制差异。

## 光标移动与阅读定位

### 常用

| 按键 | 模式 | 作用与示例 |
|---|---|---|
| `h` / `j` / `k` / `l` | 普通／可视 | 左／下／上／右移动。当前 j/k 已做显示行优化：不带次数按显示行走，`5j` / `5k` 则按文件实际行走。不要加 Alt：Alt+h/j/k/l 由 Niri 切换窗口或工作区。 |
| `w` / `b` / `e` | 普通／可视 | 下一个单词开头／当前或前一个单词开头／单词末尾；`3w` 前进三个单词。 |
| `0` / `^` / `$` | 普通／可视 | 物理行第 1 列／第一个非空白字符／行末。带缩进的代码中，`^` 通常比 0 实用。 |
| `gg` / `G` | 普通／可视 | 文件开头／文件末尾。`120G` 直接跳到第 120 行；也可输入 `:120`。 |
| `Ctrl+d` / `Ctrl+u` | 普通 | 向下／向上移动约半屏；具体行数受 scroll 选项影响。 |
| `zz` | 普通 | 保持光标所在文本位置，把这一行置于窗口中部，便于阅读上下文。 |
| `%` | 普通／可视 | 在可识别的成对括号之间跳转，例如 `(` 与 `)`、`{` 与 `}`；不是“查找引用”。 |

### 不常用

| 按键 | 模式 | 作用与示例 |
|---|---|---|
| `W` / `B` / `E` | 普通／可视 | 按以空白分隔的大词移动；例如 `std::vector<int>` 通常作为一个整体，而小写 w 会按标点进一步拆分。 |
| `f字符` / `F字符` | 普通／可视 | 在当前行向右／向左找到指定字符，光标落在它上面。`f;` 找到右侧分号。 |
| `t字符` / `T字符` | 普通／可视 | 找到指定字符前一格／后一格。`dt,` 可删除到右侧逗号之前，保留逗号。 |
| `;` / `,` | 普通／可视 | 按原方向／反方向重复最近一次 f/F/t/T 字符查找；不是重复 `/` 搜索。 |
| `{` / `}` | 普通／可视 | 跳到前一个／后一个段落边界，通常由空行区分；不等同于“上一／下一函数”。 |
| `gj` / `gk` | 普通／可视 | 按屏幕显示行移动；一条很长的源代码折成多行显示时尤其有用。 |
| `H` / `M` / `L` | 普通／可视 | 跳到当前窗口上部／中部／下部的文本行，受 scrolloff 等选项影响。 |
| `zt` / `zb` | 普通 | 把光标行滚动到窗口顶部／底部。 |

移动键通常可加次数，并可接在操作符后组成编辑命令；例如 `d3w` 是删除范围，`3w` 只是移动。[官方移动教程](https://neovim.io/doc/user/usr_03/)、[Motion 参考](https://neovim.io/doc/user/motion/)。

## 编辑、删除、撤销与重复

### 常用

| 按键 | 模式 | 作用与注意事项 |
|---|---|---|
| `x` | 普通 | 删除光标下的一个字符，文本通常进入寄存器；`3x` 删除三个字符。 |
| `dd` | 普通 | 删除当前整行，效果接近“剪切一行”；`3dd` 删除当前起三行。 |
| `D` | 普通 | 删除从光标到行末的文本，不删除下一行。 |
| `cc` / `C` | 普通 | 修改整行／从光标改到行末：删除对应内容后进入插入模式。 |
| `r字符` | 普通 | 用给定字符替换光标下一个字符而不进入持续输入模式；例如 `r,` 替换为逗号。 |
| `u` | 普通 | 撤销一个修改块。一次长时间插入可能属于同一块，不保证每次只退一个字符。 |
| `Ctrl+r` | 普通 | 重做刚刚撤销的修改。插入模式中的 Ctrl+r 是插入寄存器内容，含义不同。 |
| `.` | 普通 | 在当前位置重复最近一次可重复的文本修改，例如 ciw 修改后移到另一个单词再按点。不会重复任意 IDE 命令。 |
| `d` / `c` / `y` | 可视 | 对选区删除／修改并进入插入／复制；可视模式不用再输入移动范围。 |

### 不常用

| 按键 | 模式 | 作用与注意事项 |
|---|---|---|
| `J` / `gJ` | 普通 | 将下一行接到当前行；J 按规则处理空格，gJ 不额外插入空格。连接代码前留意注释与语法。 |
| `~` | 普通 | 切换光标下字符大小写。 |
| `gUiw` / `guiw` | 普通 | 把光标所在单词全部变成大写／小写；这是操作符加文本对象。 |
| `:earlier 5m` / `:later 5m` | 命令 | 在当前文件的撤销历史中回到约 5 分钟前／向后恢复；只在历史仍可用时有效，不是 Git 历史。 |
| `:undolist` | 命令 | 查看撤销分支概况。撤销后另作修改会形成分支，Ctrl+r 不一定回到想要的另一条分支。 |

误删后优先按 Esc，再按 u 检查恢复结果，确认后再保存。已经保存也不代表撤销历史立即消失，但不能把它当作长期备份。[官方基础修改教程](https://neovim.io/doc/user/usr_04/)、[Undo 参考](https://neovim.io/doc/user/undo/)。

## 操作符与文本对象：比反复按方向键更高效

规则是“操作符 + 范围”。`d` 删除，`c` 修改，`y` 复制；`i` 表示 inside（内部），`a` 表示 around（含外围）。在普通模式中，单独按 i 是插入；只有接在操作符或可视选择后才表示文本对象。

### 常用

| 按键 | 模式 | 作用与示例 |
|---|---|---|
| `ciw` | 普通 | 修改当前单词的内部；光标在单词中间也能改整个单词。输入新内容后按 Esc。 |
| `diw` / `yiw` | 普通 | 删除／复制当前单词，不刻意包含其旁边空格。 |
| `daw` | 普通 | 删除当前单词并按规则包含附近空白；删除句子里的一个词时通常比 diw 更整齐。 |
| `ci"` / `ci'` | 普通 | 修改双引号／单引号内部文本，保留引号；例如把 `"old"` 改为 `"new"`。 |
| `di(` / `yi(` | 普通 | 删除／复制一对圆括号内部，保留括号；`di)` / `yi)` 是相应别名。 |
| `viw` / `vi{` | 普通 | 选中单词／花括号内部，先观察范围再决定复制或修改。 |

### 不常用

| 按键 | 模式 | 作用与注意事项 |
|---|---|---|
| `da(` / `da{` / `da[` | 普通 | 删除成对括号和内部文本；`a` 会把外层括号一起算入。 |
| `ci{` | 普通 | 修改花括号内部，保留花括号。对完整代码块影响很大，先用 vi{ 确认范围更稳妥。 |
| `yip` / `dip` | 普通 | 复制／删除当前段落内部；段落不等于语法上的函数或类。 |
| `dap` | 普通 | 删除当前段落及相关空行，适合清理一段连续文字。 |
| `dit` / `dat` | 普通 | 删除 HTML/XML 标签内部／连标签整体删除；用于匹配标签文本，不是任意语言的泛型尖括号。 |

原生文本对象主要依赖分隔符与文本规则；函数、参数、语法节点等 Treesitter 文本对象属于另外的插件能力，不能只凭这张表推断键位。[官方高级编辑教程](https://neovim.io/doc/user/usr_10/)。

## 搜索与替换

### 常用

| 按键／命令 | 模式 | 作用与示例 |
|---|---|---|
| `/关键词` + Enter | 普通 | 在当前缓冲区朝文件末尾方向搜索；`?关键词` 朝文件开头方向搜索。它不是整个项目的全文搜索。 |
| `n` / `N` | 普通 | 按最近一次搜索方向继续／反方向继续；先用 ? 搜索后，n 也继续向前。 |
| `*` / `#` | 普通 | 朝文件末尾／开头方向搜索光标下完整单词。非常适合快速看当前文件里同名变量的位置。 |
| `:noh` | 命令 | 暂时清除当前搜索高亮，不删除搜索内容；之后 n 仍可继续搜索。 |
| `:s/old/new/g` | 命令 | 只替换当前行中所有匹配项；没有 g 标志时通常仅替换该行第一个。 |
| `:%s/old/new/gc` | 命令 | 全文件替换并逐项确认。确认中 y 替换、n 跳过、q 停止、a 替换后面所有项。 |

### 不常用

| 按键／命令 | 模式 | 作用与注意事项 |
|---|---|---|
| `/\Vliteral.text` | 普通 | 用 very nomagic 方式把大多数符号按字面搜索，避免点号等被当成正则。反斜线和搜索分隔符仍需留意。 |
| `/word\c` / `/word\C` | 普通 | 此次模式强制忽略／区分大小写，不必依赖当前 ignorecase、smartcase 设置。 |
| `:10,20s/old/new/gc` | 命令 | 仅在第 10 至 20 行替换并确认；首尾行都包含。 |
| `:'<,'>s/old/new/gc` | 命令 | 仅在上一次可视选区涉及的行中替换。选择后按冒号会自动带上这个范围；它按整行工作，不自动限制到矩形选区内部。 |
| `:s#old/path#new/path#g` | 命令 | 用 # 代替斜杠作分隔符，替换文件路径更易读；模式本身仍是正则。 |

替换前先保存或确认 Git 状态；c 确认标志比直接全量替换更适合陌生文件。原生命令可能匹配注释、字符串和无关同名词，修改 C++/Rust 符号时优先考虑 LSP 重命名。[官方搜索模式参考](https://neovim.io/doc/user/pattern/)。

## 复制、粘贴与寄存器

### 常用

| 按键 | 模式 | 作用与示例 |
|---|---|---|
| `yy` | 普通 | 复制当前整行；`3yy` 复制当前起三行。 |
| `Y` | 普通 | 当前配置为复制从光标到行尾的文本，不是复制整行；整行请用 yy。 |
| `y` | 可视 | 复制已经选中的内容，返回普通模式。 |
| `p` / `P` | 普通 | 在光标后／前粘贴；整行内容则放到当前行下／上。实际来源由寄存器和 clipboard 设置决定。 |
| `"0p` | 普通 | 粘贴最近一次未指定其他寄存器的 y 复制内容，通常可避开随后 d/x 删除覆盖默认来源的问题。 |
| `"+y` / `"+p` | 可视／普通 | 复制选区到系统剪贴板／从系统剪贴板粘贴；依赖 Linux 剪贴板提供程序及当前图形会话可用。 |

### 不常用

| 按键 | 模式 | 作用与注意事项 |
|---|---|---|
| `"ayy` / `"ap` | 普通 | 把当前行存到命名寄存器 a／从 a 粘贴。先按双引号，再按 a，再按操作。 |
| `"Ayy` | 普通 | 追加当前行到寄存器 a，保留它已有的内容；大写寄存器名用于追加。 |
| `"_dd` / `"_x` | 普通 | 删除到黑洞寄存器，不覆盖其他寄存器；适合保留之前的复制内容。 |
| `Ctrl+r a` | 插入 | 插入寄存器 a 的内容。这里 a 只是寄存器名，不是普通模式的追加输入命令。 |
| `:registers` | 命令 | 查看寄存器内容，可能显示剪贴板、复制过的密码、宏等敏感信息；不要随意截图分享。 |

“删除”往往兼具剪切作用，所以连续删除后直接 p 可能粘贴出最近删掉的文本。系统剪贴板与 Zellij 的复制缓冲区也不是同一个概念；出问题先确认内容到底存在哪里。[官方寄存器参考](https://neovim.io/doc/user/change/#registers)。

## 缩进与折叠

### 常用

| 按键 | 模式 | 作用与注意事项 |
|---|---|---|
| `>>` / `<<` | 普通 | 当前行增加／减少一级缩进；`3>>` 处理当前起三行。一级宽度由文件类型与 shiftwidth 决定。 |
| `>` / `<` | 可视 | 对选区涉及的行增加／减少缩进；若选区退出，可用 gv 重新选中。下面的 Tab 映射明确保留选择。 |
| `Tab` / `Shift+Tab` | 可视 | 当前配置把选区增加／减少一级缩进，并重新选中原范围，方便连续调整。这里不是插入模式的补全键。 |
| `==` | 普通 | 按当前缩进规则重缩进当前行；不是完整的 clang-format 或 rustfmt 格式化。 |
| `za` | 普通 | 切换光标处折叠的打开／关闭；已有折叠范围时才有效。 |
| `zo` / `zc` | 普通 | 打开／关闭光标处一级折叠；不会删除代码。 |

### 不常用

| 按键 | 模式 | 作用与注意事项 |
|---|---|---|
| `gg=G` | 普通 | 从文件首行重缩进到末行，改动可能覆盖整文件；先保存或确认版本控制状态。 |
| `zR` / `zM` | 普通 | 打开所有折叠／关闭所有可折叠区域，适合阅读文件结构。 |
| `zO` / `zC` | 普通 | 递归打开／关闭光标处及其内部折叠。 |
| `zi` | 普通 | 切换折叠功能是否启用；没有折叠范围时不会凭空生成函数折叠。 |
| `:set foldmethod? foldenable?` | 命令 | 查看当前窗口的折叠方式和启用状态，只查询不改配置。 |

折叠按当前窗口的 foldmethod 工作；手动、缩进和表达式折叠各不相同，因此不要把“按键无反应”直接理解为插件损坏。[官方折叠帮助](https://neovim.io/doc/user/fold/)。

## 窗口、缓冲区与标签页

缓冲区是编辑中的文件内容，窗口是显示缓冲区的一个视口，Neovim 标签页是一组窗口布局。同一个文件可同时显示在多个窗口里。顶栏的 bufferline 常用来显示缓冲区，不能据此把它们都当作原生标签页；Zellij 标签页则是外层终端工作空间。

### 常用

| 按键／命令 | 模式 | 作用与注意事项 |
|---|---|---|
| `:split` / `:vsplit` | 命令 | 创建上下／左右分屏；加文件名可打开另一个文件，例如 `:vsplit src/main.cpp`。 |
| `\|` / `\` | 普通 | 当前配置的左右／上下分屏快捷键，分别等价于 vsplit / split；竖线通常用 Shift+反斜杠输入。 |
| `Ctrl+w h/j/k/l` | 普通 | 转到左／下／上／右的 Neovim 分屏；先按 Ctrl+w，再按方向字母。不是移动 Niri 窗口。 |
| `Ctrl+w w` | 普通 | 在当前标签页的窗口之间循环。 |
| `Ctrl+h/j/k/l` | 普通 | 当前配置还提供左 / 下 / 上 / 右的直接分屏导航。向下的内部映射记为 `<NL>`；若终端增强键盘编码使 Ctrl+j 不匹配，使用 `Ctrl+w j`。 |
| `Ctrl+w =` | 普通 | 让当前标签页的分屏尺寸尽量均等。 |
| `:close` | 命令 | 关闭当前分屏，但不能关闭最后一个窗口；不等同于删除文件。 |
| `:ls` / `:buffer 编号` | 命令 | 列出缓冲区／转到指定缓冲区，例如 `:buffer 3`；文件编号可先在 ls 中查看。 |
| `:bnext` / `:bprevious` | 命令 | 切换到缓冲区列表中的下一个／上一个；不一定等同于最近访问顺序。 |

### 不常用

| 按键／命令 | 模式 | 作用与注意事项 |
|---|---|---|
| `Ctrl+w H/J/K/L` | 普通 | 把当前分屏移动到最左／下／上／右侧；大写移动布局，小写只是切换焦点。 |
| `Ctrl+w +` / `Ctrl+w -` | 普通 | 增大／减小当前窗口高度；可加次数，例如先按 5，再按 Ctrl+w，最后按 +。 |
| `Ctrl+w >` / `Ctrl+w <` | 普通 | 增大／减小当前窗口宽度。 |
| `:only` | 命令 | 只保留当前窗口；有未保存修改时可能拒绝关闭其他窗口。不要习惯性加 !。 |
| `:bdelete` | 命令 | 从缓冲区列表移除当前缓冲区，通常不会删除磁盘文件；多窗口布局可能随之变化，有未保存修改会受保护。 |
| `:tabnew` / `:tabedit 文件名` | 命令 | 新建原生 Neovim 标签页，分别为空缓冲区／指定文件建立布局。 |
| `gt` / `gT` | 普通 | 下一个／上一个原生标签页；不是切换 Zellij 标签页。 |
| `:tabclose` | 命令 | 关闭当前原生标签页及其窗口；留意其中是否有未保存缓冲区。 |

记住三层导航：Niri 用 Alt 管桌面窗口，Zellij 用 Win 管终端窗格，Neovim 用自身窗口按键管理文件分屏。[官方窗口帮助](https://neovim.io/doc/user/windows/)、[标签页帮助](https://neovim.io/doc/user/tabpage/)。

## 注释与取消注释

注释键根据当前文件类型的注释规则处理文字。它们会真实修改源码，需要保存；注释不是删除文件，也不保证被注释后的程序仍可编译。

### 常用

| 按键 | 模式 | 功能与示例 |
|---|---|---|
| `gcc` | 普通 | 注释或取消注释当前行；依次按 g、c、c。 |
| `Space /` | 普通 | 当前配置中与 gcc 同用途；最后一个键是斜杠。 |
| `gc` | 可视 | 对已经选中的内容切换注释状态；先用 V 加 j/k 选择多行，再按 g、c。 |
| `Space /` | 可视 | 对选区切换注释，适合已经使用 Space 前缀的习惯。 |

### 不常用

| 按键 | 模式 | 功能与提醒 |
|---|---|---|
| `gcap` | 普通 | 注释当前段落范围；gc 是注释操作符，ap 是段落对象。空行决定的段落不等于函数。 |
| `gco` | 普通 | 在下方加入注释输入行；最后为小写 o。 |
| `gcO` | 普通 | 在上方加入注释输入行；最后为大写 O。 |

多语言混合文档、尚未完整解析的代码及自定义 commentstring 可能影响注释格式，先检查结果，再保存或构建。误操作可用 u 撤销。

## 代码结构导航与 Treesitter 文本对象

这一章是当前插件配置提供的结构化操作，和原生的 `iw`、`i(`、`ip` 不同。它们要求当前语言有可用的解析器和对应查询；具体边界由语法查询定义，不能简单按键名字猜范围。

### 常用

| 按键 | 模式 | 功能与示例 |
|---|---|---|
| `[f` / `]f` | 普通 / 可视 / O | 到前一个 / 后一个函数起始位置。 |
| `[F` / `]F` | 普通 / 可视 / O | 到前一个 / 后一个函数结束位置；大写 F。 |
| `vaf` / `vif` | 普通进入可视 | 选择函数整体 / 函数内部，先检查选区再操作。 |
| `yaf` | 普通 | 复制查询认定的整个函数范围；比拖动选区更适合整函数复制。 |
| `vaa` / `via` | 普通进入可视 | 选择参数及外围范围 / 参数内部；例如检查函数调用中的某个参数。 |

操作符可以替换：`yaf` 是复制函数，`daf` 是删除函数，`cif` 是修改函数内部。**后两者会真正改动代码**，不熟悉时先用 `vaf` / `vif` 观察范围，再按 y/d/c。

### 不常用

| 对象 / 按键 | 模式 | 功能与限制 |
|---|---|---|
| `ac` / `ic` | 可视 / O | 类整体 / 类内部，例如 `vac` 先选择类。 |
| `ak` / `ik` | 可视 / O | 代码块整体 / 内部；不是普通模式直接输入 a、k。 |
| `ao` / `io` | 可视 / O | 循环整体 / 内部。 |
| `a?` / `i?` | 可视 / O | 条件结构整体 / 内部；最后一个键是问号。 |
| `aa` / `ia` | 可视 / O | 参数整体 / 内部。 |
| `[a` / `]a`、`[A` / `]A` | 普通 / 可视 / O | 前后参数的起始 / 结束；大写 A 对应结束。 |
| `[k` / `]k`、`[K` / `]K` | 普通 / 可视 / O | 前后代码块的起始 / 结束。 |
| `<A` / `>A` | 普通 | 与前一个 / 后一个参数交换；A 为大写。会改动源码，先检查参数副作用与顺序。 |
| `<F` / `>F` | 普通 | 与前一个 / 后一个函数交换。会产生较大范围的代码修改。 |
| `<K` / `>K` | 普通 | 与前一个 / 后一个代码块交换。 |
| `an` / `in` | 可视 / O | 选择父层外部节点 / 子层内部节点；这是语法节点选择，不是插入模式。 |
| `[n` / `]n` | 可视 | 选择前一个 / 后一个语法节点。 |
| `[N` / `]N` | 可视 | 选择前一个 / 后一个同级语法节点；大写 N。 |

结构导航不是编译器的语义分析。源码暂时不完整或解析器查询不能识别某个新语法时，结构范围可能不符合预期；可退回原生括号、文本对象、搜索或 LSP 导航。

## 标记、跳转历史与宏

### 常用

| 按键 | 模式 | 作用与示例 |
|---|---|---|
| `Ctrl+o` | 普通 | 回到跳转列表中的较早位置；例如从定义跳转后回到调用处。它不是撤销编辑。 |
| `Ctrl+i` | 普通 | 向较新的跳转位置前进。许多终端把它与 Tab 视为同一个键，最终是否可用以当前映射为准，不要直接推断 Tab 在所有模式都能跳转。 |
| `ma` | 普通 | 把当前文件位置标记为 a；可选择任意小写字母作为本文件书签。 |
| `'a` | 普通 | 回到标记 a 所在行的第一个非空白处；反引号再按 a 则尽量回到精确列。 |

### 不常用

| 按键／命令 | 模式 | 作用与注意事项 |
|---|---|---|
| `mA` / `'A` | 普通 | 设置／跳转到大写跨文件标记；可能因此打开另一个文件。 |
| `g;` / `g,` | 普通 | 到当前文件较早／较新的修改位置；与 Ctrl+o/i 的跳转历史不同，也不改变文本。 |
| `:jumps` / `:changes` / `:marks` | 命令 | 分别查看跳转记录、当前文件修改位置、标记；可能显示文件路径和文本，不要无检查分享输出。 |
| `qa` → 操作 → `q` | 普通 | 开始把按键录到寄存器 a，完成一段可重复编辑后用 q 停止录制；这里不是 `:qa`“退出全部”。 |
| `@a` / `@@` | 普通 | 执行寄存器 a 中的宏／再次执行最近使用的宏。执行前确认起始位置和内容结构一致。 |
| `5@a` | 普通 | 连续执行宏 a 五次；宏会真实修改文本、触发其中记录的命令，先用单次 @a 验证，避免直接大次数执行。 |

宏和命名寄存器共享字母名称：`"ayy` 会改写寄存器 a，也就可能覆盖先前录在 a 的宏。`u` 与 `.` 处理修改，`Ctrl+o` 与 `g;` 处理位置；把这两类分清，阅读和重构时会更稳定。[官方跳转参考](https://neovim.io/doc/user/motion/#jump-motions)、[宏与重复参考](https://neovim.io/doc/user/repeat/)。

## 文件树与文件、内容搜索

文件树用于浏览目录结构；搜索选择器用于按名字或内容快速定位。以下入口均在普通模式使用，`Space` 是先按再松开的前缀，不需要一直按住。

### 常用

| 按键 | 功能 | 典型用途 |
|---|---|---|
| `Space e` | 显示或隐藏 Neo-tree 文件树 | 查看项目文件夹，确认源码位置。 |
| `Space o` | 在文件树与编辑区域之间切换焦点 | 文件树已经打开，只想把光标移过去。 |
| `Space f f` | 按文件名查找文件 | 输入 `main`，快速定位 `main.cpp`。 |
| `Space f w` | 搜索项目文件里的文字 | 查找函数名、错误信息或配置项。 |
| `Space f c` | 搜索光标处的单词 | 光标放在函数名上，查它出现的位置。 |
| `Space f b` | 搜索当前已经打开的缓冲区 | 多个文件间切换，不必重新找路径。 |
| `Space f o` | 查找最近打开的文件 | 找回刚才编辑过的文件。 |
| `Space f l` | 在当前缓冲区中搜索行 | 在长文件里按内容定位。 |
| `Space f s` | 综合搜索缓冲区、最近文件和文件 | 不确定文件是否已经打开时使用。 |
| `Space f Enter` | 恢复上一次搜索选择器 | 搜索后退出了，想继续使用刚才的条件。 |

文件树获得焦点后：`h` 折叠或到父项，`l` 展开或打开，`Enter` 打开文件/目录，`q` 关闭文件树，`?` 查看文件树帮助。这里 `Space` 本身用于展开/折叠节点，不要把编辑窗口的 Leader 序列原样套进去。

搜索选择器内，输入文字过滤；`Ctrl+n/p`、`Ctrl+j/k` 或方向键移动结果，`Enter` 确认打开。输入框中按 `Esc` 通常先退出插入模式，再按 `Esc` 取消；`Ctrl+c` 可在输入模式取消。普通模式下 `q` 取消，`?` 查看当前选择器帮助。

例子：先用 `Space f f` 打开某个 `.cpp`，再把光标移到函数名上按 `Space f c` 查找它的文字引用。文字搜索不等于 LSP 的语义引用搜索，注释和同名符号也可能命中。

搜索范围取决于当前项目/工作目录和选择器的忽略规则。没有找到文件时，先检查所在项目，而不是立即认为文件丢失。

### 不常用

| 按键 | 功能 | 注意事项 |
|---|---|---|
| `Space f F` | 查找更多文件，包括通常被隐藏/忽略的范围 | 大写 `F`；结果可能包含构建产物，搜索会更嘈杂。 |
| `Space f W` | 在更宽的文件范围内搜索文字 | 大写 `W`；大型构建目录可能明显拖慢搜索。 |
| `Space f g` | 查找 Git 跟踪的文件 | 适合只关心仓库文件，未跟踪的新文件可能不在结果里。 |
| `Space f O` | 在当前工作目录范围查最近文件 | 大写 `O`，不同于全局最近文件 `Space f o`。 |
| `Space f p` | 查找已记录的项目 | 不是自动扫描硬盘上的所有项目。 |
| `Space f a` | 查找 AstroNvim 配置文件 | 修改配置前先备份，写入后通常要重新启动编辑器。 |
| `Space f T` | 查找 TODO 等标记 | 大写 `T`；适合汇总 `TODO`、`FIXME`。 |
| `[T` / `]T` | 跳到前一个/后一个 TODO 标记 | 普通模式，方括号与大写 `T` 顺序输入。 |
| `Space f '` | 查找标记 | 最后一个键是单引号。 |
| `Space f r` | 查看寄存器 | 检查最近复制/删除内容。 |
| `Space f u` | 查找撤销历史 | 用于找回编辑状态，不代替 Git 或文件备份。 |

文件树内的较少用操作（只在 Neo-tree 窗口中）：

| 按键 | 功能与注意事项 |
|---|---|
| `a` / `A` | 新建文件/新建目录；大写 `A` 为目录。 |
| `r` / `m` / `d` | 重命名/移动/删除磁盘上的文件；先检查目标和确认框，不能当普通文字编辑。 |
| `y` / `x` / `p` | 把文件复制/剪切到树的操作剪贴板，再粘贴到目标目录。 |
| `s` / `S` / `t` | 垂直分屏/水平分屏/新标签页打开；注意大小写。 |
| `H` / `R` / `P` | 切换隐藏文件/刷新/切换预览。 |
| `Y` | 选择并复制路径等表示形式，不是 `y` 的文件复制。 |
| `O` 或 `Shift+Enter` | 用系统默认应用打开文件；可能启动外部程序。 |
| `[b` / `]b` | 切换前一个/后一个文件树来源，如文件系统、缓冲区等。 |
| `f f` / `f w` | 在选定目录内找文件/搜索文字；`f F`、`f W` 为更宽范围。 |
| `T h` / `T v` / `T f` | 在选定目录启动水平/垂直/浮动集成终端。 |

搜索选择器内，`Ctrl+s/v/t` 分别在水平分屏/垂直分屏/标签页打开；`Tab`、`Shift+Tab` 勾选并移动，`Ctrl+a` 全选，`Ctrl+q` 发送到 quickfix。`Ctrl+f/b` 滚动预览，`Ctrl+d/u` 滚动结果，`Ctrl+↑/↓` 切换输入历史。

这些是局部面板映射：搜索器的 `Ctrl+q` **不是强退**，`Ctrl+s` **不是保存**；文件树的 `Ctrl+s` 是快速跳转。部分选择器还有 Alt 开关，但本机 Niri 使用 Alt 组合键，可能先被桌面拦截，优先使用界面可达操作。

## 代码导航、LSP 与诊断

LSP 是“理解代码”的语言服务。C/C++ 使用系统 clangd，Rust 使用 rust-analyzer。以下带有语言服务的动作，需要当前缓冲区已经连接相应服务；普通文本或 Markdown 不一定具备同样能力。

### 常用

| 按键 | 模式 | 功能与说明 |
|---|---|---|
| `g d` | 普通 | 跳到光标处符号的定义，例如从调用处进入函数实现。 |
| `K` | 普通 | 显示符号文档、类型等悬浮信息；是大写 `K`。 |
| `Space l R` | 普通 | 搜索符号引用；最后是大写 `R`，用于语义上的“在哪里使用”。 |
| `Space l r` | 普通 | 重命名符号；最后是小写 `r`，可能修改多个文件。 |
| `Space l a` | 普通 | 请求代码操作，例如服务提供的修复、补充导入等。 |
| `Space l d` 或 `g l` | 普通 | 查看当前位置诊断的详细信息。 |
| `[d` / `]d` | 普通 | 跳到当前文件前一个/后一个诊断，包括警告等。 |
| `[e` / `]e` | 普通 | 只在错误之间跳转。 |
| `[w` / `]w` | 普通 | 只在警告之间跳转。 |
| `Space l D` | 普通 | 打开诊断搜索；最后为大写 `D`。 |
| `Space l s` | 普通 | 搜索文档符号，如函数、类和变量。 |
| `Space l S` | 普通 | 打开/关闭符号大纲；最后为大写 `S`。 |
| `Space l h` | 普通 | 显示函数签名，查看参数与类型。 |
| `Ctrl+s` | 插入 | 显示函数参数签名，**不是保存**。 |

阅读代码时可按“`g d` 进入定义 → `K` 看类型/说明 → `Space l R` 看使用位置”的顺序操作。跳转前后仍可使用 Neovim 的跳转历史返回，避免反复重新搜索文件。

重命名是修改代码，不只是改屏幕上的一个词。操作前保存并确认 Git 状态，操作后检查受影响文件。不能把 `Space l r` 与 `Space R` 混淆：后者是文件重命名，不是符号重命名。

### 不常用

| 按键 | 模式 | 功能与说明 |
|---|---|---|
| `g D` | 普通 | 跳到声明；最后是大写 `D`，与 `g d` 的定义不同。 |
| `g I` | 普通 | 查找实现；最后为大写 `I`。 |
| `g y` | 普通 | 跳到当前符号的类型定义。 |
| `Space l G` | 普通 | 搜索整个工作区的符号；最后为大写 `G`。 |
| `Space l A` | 普通 | 请求 source 类代码操作；具体项目由服务决定。 |
| `[D` / `]D` | 普通 | 跳到当前缓冲区第一个/最后一个诊断。 |
| `[y` / `]y` | 普通 | 跳到前一个/后一个符号。 |
| `[Y` / `]Y` | 普通 | 向外层方向查前一个/后一个符号；最后为大写 `Y`。 |
| `[r` / `]r` | 普通 | 跳到前一个/后一个高亮引用；依赖语言服务提供引用信息。 |
| `Space l i` | 普通 | 查看语言服务信息，确认 clangd 等是否已连接。 |
| `Space l I` | 普通 | 查看 none-ls 信息；最后为大写 `I`。 |
| `g r a` / `g r n` | 普通 | Neovim 原生代码操作/重命名入口，与上述 Leader 入口用途相近。 |
| `g r r` / `g r i` / `g r t` | 普通 | 原生引用/实现/类型定义入口。 |
| `g O` | 普通 | 原生文档符号列表；最后为大写 `O`。 |
| `g r x` | 普通 | 执行当前位置可用的 CodeLens；服务不提供时无实际操作。 |

C++20 Modules 的补全和导航仍受 clangd 实验性模块支持限制。项目能编译，不保证每一种 `import` 写法都能完整提示；先检查 CMake 配置、编译数据库及 clangd 连接状态。

## 格式化与代码补全、片段

格式化负责调整代码排版，补全负责插入候选，代码片段则可能一次插入带多个占位位置的模板。三者不是同一个功能。

### 常用

| 按键 | 模式/条件 | 功能与说明 |
|---|---|---|
| `Space l f` | 普通；有格式化服务 | 格式化当前缓冲区。C/C++ 通过系统 clang-format，规则由项目配置等决定。 |
| `Ctrl+Space` | 插入；补全系统启用 | 显示候选，再按可显示/隐藏候选文档。 |
| `Ctrl+n` / `Ctrl+p` | 插入 | 选下一个/上一个候选；需要时也会显示补全菜单。 |
| `Tab` / `Shift+Tab` | 插入；上下文相关 | 菜单中切换候选；片段活跃时可跳转占位符；否则回退到原按键功能。 |
| `Enter` | 插入；有可接受候选 | 接受补全；不满足补全条件时回退为回车原功能。 |
| `Ctrl+e` | 插入；菜单显示时 | 隐藏补全菜单。 |
| `Space u f` | 普通；格式化服务已连接 | 切换当前缓冲区自动格式化。 |

例如输入函数名前几个字母，按 `Ctrl+n` 调出或选择候选，确认候选正确后按 `Enter`。如果展开了带参数占位符的片段，再按 `Tab` 前进、`Shift+Tab` 后退。

`Tab` 不是无条件“确认第一条补全”，也不是永远插入缩进；它会根据菜单与片段状态执行不同动作。只是想关闭菜单继续输入时用 `Ctrl+e`。

### 不常用

| 按键 | 模式/条件 | 功能与说明 |
|---|---|---|
| `Ctrl+j` / `Ctrl+k` | 插入；补全菜单 | 选择下一个/上一个候选，未处理时回退。 |
| `↓` / `↑` | 插入；补全菜单 | 选择下一个/上一个候选，未处理时回退。 |
| `Ctrl+d` / `Ctrl+u` | 插入；补全文档可滚动 | 向下/上滚动候选文档；否则回退到原按键功能。 |
| `Space u c` | 普通 | 切换当前缓冲区自动补全。 |
| `Space u C` | 普通 | 切换全局自动补全；最后是大写 `C`。 |
| `Space u F` | 普通；格式化服务已连接 | 切换全局自动格式化；最后为大写 `F`。 |
| `Space u ?` | 普通；相应 LSP 能力可用 | 切换自动函数签名提示。 |

关闭自动格式化不会替你撤销已经发生的格式变更；关闭补全也不会卸载语言服务器。C/C++ 格式化并非 clangd 和 clang-format 同时执行：本机配置排除了 clangd 的格式化以避免重复。

Rust 当前检查使用 Clippy，并请求 Cargo 全部 features；若项目的 features 相互冲突，要调整项目/服务配置，不是靠关闭诊断来修复。Markdown 补全目前主要提供勾选框、callout 等候选，并不是完整 Markdown 语言服务器。

## CMake 配置、构建与测试

这一组是本机新增的原生异步工作流。所有按键均在普通模式；`Space m` 打开 CMake 功能组。

### 常用

| 按键 | 等价命令 | 具体执行顺序 |
|---|---|---|
| `Space m c` | `:CMakeConfigure` | 只配置工程，生成/更新构建系统，并请求导出 `compile_commands.json`。 |
| `Space m b` | `:CMakeBuild` | 先配置，配置成功后构建。 |
| `Space m t` | `:CMakeTest` | 先配置，再构建，构建成功后运行 CTest。 |
| `Space m l` | `:CMakeLog` | 打开最近任务的只读输出日志。 |
| `Space m i` | `:CMakeInfo` | 查看项目根目录、preset、构建目录和当前任务状态。 |
| `Space x q` | `:copen` | 打开 quickfix 错误列表；构建失败且错误可解析时也会自动显示。 |
| `[q` / `]q` | `:cprevious` / `:cnext` | 跳到前一条/后一条 quickfix 项。 |

推荐顺序：编辑源码 → `Space w` 保存 → 首次使用时 `Space m c` 检查配置 → `Space m b` 构建 → 需要测试时 `Space m t`。

**这些 CMake 命令不会先自动保存缓冲区。** 没有保存的修改尚不在磁盘上，编译器看不到它们。保存所有改过的相关文件后再构建，不能只保存当前文件却忽略其他未保存的头文件。

配置和构建在后台进行，不必连续重复触发；同一个项目同时只接受一项此助手任务。成功构建不等于运行了程序，`Space m t` 也只运行工程注册的 CTest 测试，不会把任意可执行文件当测试。

### 不常用

| 按键 | 等价命令 | 功能与限制 |
|---|---|---|
| `Space m p` | `:CMakePreset` | 选择可用的 configure preset，当前编辑器会话内按项目记住。 |
| `Space m x` | `:CMakeStop` | 取消此助手为当前项目启动的任务，不停止你在独立终端启动的构建。 |
| `[Q` / `]Q` | `:crewind` / `:clast` | 到 quickfix 第一条/最后一条；最后为大写 `Q`。 |

只有一个可用 configure preset 时自动使用；有多个时提示选择。不需要每次手动执行 `Space m p`。关闭并重新启动 Neovim 后，助手不会把上次会话选择写进项目文件。

没有 preset 时默认使用项目的 `build` 目录：已有 CMake 缓存就尊重它；没有缓存时新建 Ninja Debug 构建，编译器由工程、环境和 CMake 正常选择。

重要边界：助手只读取 **configure presets**，不会套用 build/test preset 专属的 target、环境和其他选项。如果项目依赖这些设置，应在终端使用项目要求的 `cmake --build --preset <名称>` 或 `ctest --preset <名称>`。

构建目录以 CMake 实际配置结果为准，不能默认永远是 `./build`。助手不会修改项目 `.clangd`，也不会替你建立 `compile_commands.json` 软链接；clangd 是否能找到数据库还要看工程设置。

默认并行构建为 2，多配置生成器默认选 Debug。无测试时 CTest 会报告失败；编译错误无法解析到 quickfix 时查看日志，不代表助手没有捕获输出。

日志只保存在当前 Neovim 会话内，保留最近 1500 行，每行最多 8192 字节。`Space m l` 打开的是调用当时的日志视图，需要更新内容时重新打开。

## LLDB 断点调试

本机通过 nvim-dap 与系统 `lldb-dap` 调试 C/C++/Rust。调试动作通常需要程序已启动，并在暂停位置才能查看局部变量或单步。

### 常用

| 按键 | 替代键 | 功能 |
|---|---|---|
| `Space d b` | `F9` | 在当前行添加或移除断点。 |
| `Space d c` | `F5` | 未启动时启动调试；已暂停时继续运行。 |
| `Space d o` | `F10` | 单步越过：执行当前语句，不进入被调用函数内部。 |
| `Space d i` | `F11` | 单步进入：有调试信息时进入被调用函数。 |
| `Space d O` | — | 单步跳出当前函数；最后是大写 `O`。 |
| `Space d u` | — | 显示或隐藏调试界面。 |
| `Space d h` | — | 查看光标处表达式的调试悬浮信息。 |
| `Space d Q` | — | 终止当前调试会话；最后为大写 `Q`。 |

流程示例：保存代码 → `Space m b` 构建带调试信息的程序 → 源码行 `Space d b` 设置断点 → `Space d c` → 在 `Executable:` 提示中填写实际可执行文件路径。

**调试不会自动先构建。** 修改源码后直接按 `F5`，可能运行旧二进制。无调试信息或高优化构建也可能导致断点不对应、变量被优化掉，这并不是快捷键失效。

启动器按项目记住当前会话上次选择的程序；工作目录来自当前源码项目。取消输入、空输入或选择非可执行文件会放弃该次启动；相对路径按项目根目录解析。

### 不常用

| 按键 | 模式 | 功能与提醒 |
|---|---|---|
| `Space d C` | 普通 | 条件断点；最后为大写 `C`，只有表达式满足时暂停。 |
| `Space d B` | 普通 | 清除全部断点；最后为大写 `B`，不是只删当前行。 |
| `Space d p` 或 `F6` | 普通 | 暂停正在运行的调试程序。 |
| `Space d r` | 普通 | 重新启动调试。 |
| `Space d s` | 普通 | 运行到光标位置，适合跳过不关心的中间语句。 |
| `Space d E` | 普通 | 手动输入表达式求值。 |
| `Space d E` | 可视 | 对选中的内容求值；最后为大写 `E`。 |
| `Space d R` | 普通 | 打开/关闭调试 REPL；最后为大写 `R`。 |
| `Space d q` | 普通 | 关闭当前会话；小写 `q` 与大写 `Q` 的终止操作要区分。 |

调试表达式可能调用函数或改变程序状态，不要对有副作用的表达式随意求值。当前默认启动配置不填程序参数；需复杂参数、环境或启动方式时应明确配置，而不是把它们拼进可执行文件路径输入框。

组合功能键受终端编码影响；手册优先给出已经确认的 `Space d …` 入口，不要求记住 Shift/Ctrl 加功能键的终端编码别名。

## Markdown 编辑与渲染

当前插件是 render-markdown.nvim：它把 Markdown 在编辑器内装饰得更易读，不会把源文件转换成别的格式。

### 常用

| 按键/命令 | 模式 | 功能与说明 |
|---|---|---|
| `Space u m` | 普通 | 开启/关闭 Markdown 渲染；`m` 为小写。 |
| `:RenderMarkdown toggle` | 命令行 | 与上述切换作用相同，执行后按 Enter。 |
| `:RenderMarkdown preview` | 命令行 | 打开插件的渲染分屏，仍在 Neovim 内。 |
| `Space u w` | 普通 | 开关视觉自动折行，阅读长段落时有用。 |

打开 `.md` 时会按需加载插件。标题、代码块、表格、列表、链接和任务勾选框可以被装饰；当前光标行及插入模式通常保留更多原始文本，便于编辑标记。

装饰不改变文件正文。屏幕看见勾选框图标时，磁盘上仍是 Markdown 源码；关闭渲染即可检查真实标记。视觉折行也不等于给段落实际插入换行。

### 不常用

| 命令 | 功能与说明 |
|---|---|
| `:RenderMarkdown enable` / `:RenderMarkdown disable` | 明确开启/关闭渲染，比“不知道当前状态时切换”更直接。 |
| `:RenderMarkdown buf_enable` / `:RenderMarkdown buf_disable` | 只改变当前缓冲区的渲染状态。 |
| `:RenderMarkdown debug` | 查看渲染调试信息，用于排查语法装饰问题。 |

此配置关闭可选 TeX 渲染，超过 2 MB 的文件默认跳过普通渲染。它不是浏览器 HTML 预览服务，也不提供原生图片显示；不要把没有显示图片或 LaTeX 公式误判为漏装某个快捷键。

本次 Markdown 插件没有额外安装格式化器、linter 或外部 Markdown 语言服务，因此不能假定 Markdown 一定拥有 `Space l f`、符号重命名等全部代码开发能力。

## Git 浏览与仓库界面

这些入口用于查看仓库状态和历史。它们不是“一键提交并推送”的工作流，也不能替代对更改内容的审核。

### 常用

| 按键 | 模式 | 功能与说明 |
|---|---|---|
| `Space g t` | 普通 | 打开 Git 状态选择器，查看仓库中的更改文件。 |
| `Space g c` | 普通 | 查看仓库提交历史。 |

看历史时先确认当前所在仓库；同一个 Neovim 会话可打开多个项目，工作目录和当前文件不一致时尤其要注意。状态面板显示的未跟踪文件，并不代表它已经被提交或备份。

本机有 gitsigns 插件，但不能据此套用其他发行版的 `Space g h`、`Space g s` 等映射。本手册以实际导出的有效映射为准，不把“插件可能支持的功能”写成“本机已绑定的按键”。

## Neovim 集成终端

这里的终端是 Neovim 内的 ToggleTerm，不是 Zellij 窗格。Niri 的 Alt 组合键、Zellij 的 Win 组合键由外层程序处理，不是这组映射的控制范围。

### 常用

| 按键 | 模式 | 功能与说明 |
|---|---|---|
| `F7` 或 `Ctrl+'` | 普通/插入/终端 | 开关集成终端；单引号键不是反引号。 |
| `Ctrl+\ → Ctrl+n` | 终端输入 | 返回终端缓冲区的普通模式，随后才可使用普通模式移动、搜索、复制和 Space 命令；不是退出 shell。 |
| `i` | 终端普通 | 回到终端输入状态，把后续输入发送给 shell/终端程序。 |
| `Ctrl+c` | 终端输入 | 传给终端内程序，通常用于中断前台任务；程序可自定义处理，不等于停止 CMake helper 或退出 Zellij。 |
| `Space t f` | 普通 | 浮动终端，临时执行命令后返回代码。 |
| `Space t h` | 普通 | 底部水平分屏终端。 |
| `Space t v` | 普通 | 右侧垂直分屏终端。 |
| `Ctrl+h/j/k/l` | 终端 | 分别移到左/下/上/右相邻 Neovim 窗口。 |

打开终端后键入 `cmake --build --preset <名称>`，是 shell 命令而不是 Neovim 命令；以冒号开头的 `:CMakeBuild` 则是编辑器命令。二者任务管理互相独立，`Space m x` 不会负责停止前者。

隐藏 ToggleTerm 通常不是结束其中的 shell 或构建程序；运行长任务时不要把“窗口消失”当成“程序已退出”。终端内 `Ctrl+j` 可能被窗口导航使用，不应假定仍然作为 shell 输入。

### 不常用

| 按键/命令 | 模式 | 功能与提醒 |
|---|---|---|
| `Space t p` | 普通 | 打开 Python 交互终端；要求相应解释器可用。 |
| `Space t n` | 普通 | 打开 Node.js 交互终端；不是运行当前项目的 npm 脚本。 |
| `:TermSelect` | 命令行 | 选择已管理的集成终端。 |
| `:ToggleTermToggleAll` | 命令行 | 切换所有 ToggleTerm 窗口的显示状态。 |

终端模式下按键会先受当前终端映射影响。想给 shell/其内部程序传递本机已占用的组合键时，需要明确区分是 Neovim、Zellij、终端模拟器还是桌面拦截，不应盲目重复改一套配置。

### 常用

| 按键/命令 | 模式 | 功能与说明 |

| `Space S s` | 普通 | 保存当前会话；`S` 大写，最后 `s` 小写。 |
| `Space S f` | 普通 | 选择并载入一个已保存会话。 |
| `Space S l` | 普通 | 载入上一次会话；最后是小写 `l`。 |
| `Space f k` | 普通 | 搜索当前可用映射，忘记快捷键时先查这里。 |
| `Space f h` | 普通 | 搜索帮助文档。 |
| `Space f C` | 普通 | 搜索编辑器命令；最后为大写 `C`。 |

| `Space S S` | 保存当前目录会话；最后为大写 `S`。 |

| `Space S F` / `Space S D` | 选择载入/删除目录会话；最后均为大写。 |
| `Space p u` | 检查插件更新，不等于立即升级。 |
| `Space p i` | 安装缺失插件，可能联网下载并执行插件构建步骤。 |
| `Space p U` | 更新插件；最后是大写 `U`，可能更改版本与锁文件。 |
| `Space p S` | 同步插件，可能包含安装、清理与更新，不是无副作用的查看操作。 |

## 典型工作流程

### 常用：从打开项目到构建测试

以一个已经准备好 `CMakeLists.txt` 的 C++ 工程为例：

1. 在终端进入项目目录，运行 `nvim .`；也可以先启动 Neovim，再用 `Space f f` 找文件。
2. 按 `i` 输入代码；输入完成按 Esc（物理任一 Ctrl）。
3. 用 `Space w` 保存，必要时用 `Space l f` 格式化后再次保存。
4. 用 `Space m b` 配置并构建；多个 configure preset 时选择一次，本次编辑器会话会按项目记住。
5. 有编译错误时查看自动打开的 quickfix；用 `]q`、`[q` 在条目间跳转，错误窗口内 Enter 打开源位置。
6. 修正、保存、再次 `Space m b`。
7. 用 `Space m t` 运行工程注册的 CTest 测试。没有注册测试会报失败，不代表编译器坏了。

**构建读取磁盘上的文件。**有未保存修改时，构建结果可能还对应旧内容。构建、测试、调试是三件不同的事：构建生成程序，CTest 跑已注册测试，LLDB 调试所选程序。

### 常用：查代码、修改符号

1. `Space f w` 搜索关键词；在搜索框中筛选结果并 Enter 打开。
2. 光标放到函数/类型上，按 `gd` 看定义、按 `K` 看说明。
3. 需要改名时用 `Space l r`，而不是只对当前文件做纯文本替换。
4. 看引用用大写的 `Space l R`；返回之前位置通常用 `Ctrl+o`。
5. 用 `[d` / `]d` 检查当前文件的诊断；`Space l d` 展开当前位置的详细诊断。

### 常用：编辑 Markdown 文档

1. 打开 `.md` 文件，普通模式自动渲染标题、表格、代码块和任务列表。
2. 光标所在行会减少装饰，插入模式主要显示源文本，方便编辑；这不是渲染失效。
3. `Space u m` 在渲染和源文本显示之间切换。
4. `:RenderMarkdown preview` 打开编辑器内部的渲染分屏。
5. 用 `Space w` 保存；渲染只改变显示，不改写文件内容。

### 不常用：开始一次 LLDB 调试

1. 先保存并成功构建可执行文件，建议 Debug 构建。
2. 在需要暂停的位置按 F9 设置断点。
3. 按 F5；首次按提示选构建出的可执行文件，路径可以相对项目根目录输入。
4. 用 F10 单步跳过、F11 单步进入、`Space d O` 单步跳出；F5 继续。
5. 用 `Space d Q` 终止调试会话。

取消选择、空输入、目录或非可执行文件会中止启动。选择结果按项目保存在本次 Neovim 会话中；调试快捷键不负责自动构建，也不自动选择 CMake target。

## 按键没反应时怎么查

### 常用：先确认模式、焦点与大小写

| 现象 | 先检查什么 |
|---|---|
| 按 Space 后只输入了空格 | 是否仍在插入模式；先按逻辑 Esc，即物理 Ctrl |
| 按 Ctrl 组合键却返回普通模式 | 你按的是物理 Ctrl；本机逻辑 Ctrl 要用物理 CapsLock |
| `Space l r` 与 `Space l R` 结果不同 | 小写 r 重命名，大写 R 查引用；Shift 不能省略 |
| 相同字母在文件树里行为不同 | 插件窗口有局部映射；先回到源文件窗口 |
| Win 操作切换了 Zellij 窗格 | 属于正常分层处理，Neovim 内部分屏应使用 Ctrl+w |
| 定义、补全或格式化不可用 | 检查语言服务是否已连接、文件类型、项目根和编译数据库；不是所有语言都具备同样功能 |
| CMake 构建找不到新代码 | 先保存；再确认当前文件对应的项目及实际构建目录 |
| Markdown 当前行看起来是源码 | 光标行反隐藏、插入模式及关闭渲染都可能如此，先回普通模式查看其他行 |
| 新增 Markdown / CMake 键不存在 | 关闭自己的编辑器后重新启动，已有窗口没有被远程强制重载 |

### 不常用：直接查看当前有效绑定

以下都是在普通模式输入的命令；输入冒号后按 Enter 执行。

| 命令 | 用途 |
|---|---|
| `:verbose nmap <Space>mb` | 查看普通模式 CMake 构建键及最后定义来源 |
| `:verbose nmap <Space>um` | 查看 Markdown 开关键 |
| `:verbose imap <C-S>` | 查看插入模式 Ctrl+s 的有效映射 |
| `:verbose xmap <Tab>` | 查看可视模式 Tab 的有效映射 |
| `:map` / `:nmap` / `:imap` | 查看相应映射列表；缓冲区局部映射随当前窗口变化 |
| `:LspInfo` | 查看语言服务连接情况 |
| `:NullLsInfo` | 查看 none-ls 格式化/诊断源 |
| `:CMakeInfo` / `:CMakeLog` | 查看当前 CMake 状态和本次会话日志尾部 |
| `:messages` | 查看编辑器消息 |
| `:Lazy` / `:Mason` | 打开插件 / 开发工具管理器；打开界面本身不等于要求全部升级 |
| `:checkhealth` | 检查运行依赖；区分错误与未启用的可选功能警告 |
| `:help key-notation` | 查看官方按键记法 |
| `:help index` / `:help quickref` | 查看完整原生键索引与速查 |
| `:help i_CTRL-W` | 查看插入模式 Ctrl+w 说明；前缀 i_ 代表插入模式 |
| `:help CTRL-W` | 查看普通模式窗口操作前缀说明 |

同一键可能同时存在全局、缓冲区、插件界面映射。文档描述的是核对时的配置；以后改插件或映射后，以 `:verbose ...map` 和对应界面的帮助为准。

## 配置边界与维护说明

### 常用：哪些功能需要工程配合

- C++ 使用系统 clangd、clang-format；Rust 使用 rust-analyzer 和 Clippy。语言服务能力受工程和工具版本影响。
- C++20 Modules 可以编译，但 clangd 的跨模块提示与导航仍有实验性限制。保证构建成功、编译数据库正确，不等于所有模块提示一定完整。
- CMake helper 只使用 configure preset，不应用 build/test preset 专有的目标、参数或环境；需要这些特性时在终端使用项目自己的命令。
- Markdown 插件负责编辑器内显示和部分任务/提示项补全，不提供通用 Markdown LSP、格式化器、HTML 浏览器预览或图片显示。可选 TeX 渲染未开启，超过 2 MB 的文件默认不渲染。

### 不常用：更新与保存自己的配置

- Neovim 配置在 `~/.config/nvim`；本手册的仓库位置为 `docs/neovim-keybindings-guide.md`，本机对应 `~/.config/nvim/docs/neovim-keybindings-guide.md`。阅读副本位于 `~/Documents/Manuals/neovim-keybindings-guide.md`。
- 本手册随配置仓库版本管理；修改 `Documents/Manuals` 中的阅读副本不会自动回写仓库。按键说明更新时，应同步两处内容并按需提交；阅读文档不会更新插件。
- `Space p U`、`Space p S` 等涉及版本变动，按之前先理解差别并备份；有锁文件也不等于所有“更新”操作只检查而不修改。
- 现有开发说明在 `~/.config/nvim/LOCAL-DEVELOPMENT.txt`，Markdown 说明在 `~/.config/nvim/LOCAL-MARKDOWN.txt`。
- 学习顺序建议：模式/保存/撤销 → 移动和文本对象 → 查找/文件切换 → LSP/CMake → 调试、宏、会话和高级界面开关。
